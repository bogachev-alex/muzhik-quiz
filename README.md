# Мужицкий парфюмерный квиз

11 вопросов → мужской аромат из 32 и точка на матрице «метросексуал–лесоруб × ведомый–доминант».

- `index.html` — собранная страница (всё внутри, включая фото в base64).
- `src/` — исходники: `core.js` (вопросы, ароматы, подсчёт), `app.js`/`app2.js` (интерфейс), стили и разметка.
- `tools/build.py` собирает `index.html`, `tools/calibrate.mjs` подбирает `BIAS`, чтобы все ароматы выпадали поровну.

Фото музыкантов — Wikimedia Commons (авторы и лицензии в блоке «о квизе»). Кадры с киногероями — из фильмов и сериалов, права у студий.
